# Phone Firmware

> Source: https://www.3cx.com/docs/phone-firmwares/

Firmwares on this page applies to installations on V20. If you're running on V18, download firmware from [this page](https://www.3cx.com/docs/phone-firmware-v18/).

**Important:** If your phone's firmware is too old, it may not accept the latest version supported by 3CX. You'll need to contact the manufacturer to get the required intermediate versions and apply them in sequence. The device won't upgrade unless each required intermediate version is installed in the right order.
