# Configuring the BLF (Busy Lamp Fields) buttons of your IP Phone

> Source: https://www.3cx.com/sip-phones/busy-lamp-field-dss-keys/

BLFs can be configured from the 3CX Desktop App / PWA in the **"User > BLF tab"** and the Windows App settings.

You can configure the BLF buttons (also referred to as DSS keys) as well as the transfer method to be used when you press the BLF key.

The following BLF types are available:

- **BLF** - has 3 functions. To dial the extension, to show the presence of the extension and to pick up the call.
- **Speed Dial** - to call the extension.
- **Line Keys** - to create a new call / line from the phone.
- **Custom Speed Dial** - to make a call to an external number or to trigger dial code such as switch to out of office.
- **Shared parking** - to park or unpark a call to the shared park slot specified
- **Agent Login / Logout** - assign to Login or Logout to all call queues
- **Change status** - to change the users status to the one specified

To select the default transfer method of the BLF buttons:

1. Go to the **"User > IP phone"** tab
2. Navigate to **"Phone Options"**
3. Select between "Blind Transfer" or **"Attended/Consultative Transfer"**

⚠️ You can re-order the BLF buttons by clicking on the move handle to drag and drop to the desired position.

Phone configuration changes take effect within 24 hours. If you want them to take effect immediately, then restart the phone.
