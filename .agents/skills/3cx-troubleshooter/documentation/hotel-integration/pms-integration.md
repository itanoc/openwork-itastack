# Hotel Software / PMS Integration (Fidelio / Mitel)

> Source: https://www.3cx.com/docs/pms-integration/

## Introduction

Although most of the hotel related functions can be performed via the 3CX Web Client interface, if a Property Management System is present on the local network, it can perform actions automatically at Check-In or Check-Out. 3CX supports a wide range of hotel software systems.

## Without PMS Integration

When only using the 3CX Web Client to check-in / out guests (extensions = room number) the receptionist in question must have the user right to "User Operations" enabled for the group where rooms are located. With this right, the receptionist (extension) can do the following from the Web Client:

1. Click on any room/extension and select "Assign" to check in a guest to a room.
2. Define the guest information.
3. In case a guest leaves the room the "Clear" action can be used to check out the guest or directly "Assign" it to the next guest.

**Note**: While using 3CX's own checkin /-out procedure no billing receipt will be generated for the guest stay duration once the guest checks out of the room.

## With PMS Integration

The 3CX Hotel Module can integrate with PMS systems in the following ways:

- Via the **Mitel SX2000 PMS protocol**.
- Via the **Fidelio protocol**.

### Configuring PMS Protocol Integration (Mitel SX2000)

When using the Mitel SX2000 PMS protocol, the 3CX Hotel Module acts as a server. In other words, the PMS software sends messages to the 3CX Hotel Module. Use this for Mitel compatible hotel software such as roommaster and Brilliant / Hotel Concepts.

Access the 3CX Admin Console and go to "Integrations" > "Hotel Services". Enable the PMS integration option and specify:

- The selected PMS integration type should be **Mitel SX2000**.
- Enter the **local IP address** of the PMS System.
- The **port** must match that configured in the PMS system on your LAN.

**Note**: While using Mitel SX2000 protocol no billing interface is implemented in the protocol to advise the PMS of phone charges generated by the room!

### Configuring Fidelio Protocol Integration

The Fidelio Protocol integration can be used for Micros Fidelio and Protel hotel software. FIAS (Fidelio Interface Application Specification) is supported by the following PMS systems from MICROS-Fidelio: Fidelio Suite 6, Fidelio Suite 7, Fidelio Suite 8 & OPERA. It is NOT supported by Fidelio Xpress.

The 3CX Fidelio protocol integration acts as a **client**. This means that in this case, messages will be sent from the 3CX Hotel Module to the Fidelio Management System.

Access the 3CX Admin Console and go to "Integrations" > "Hotel Services". Enable the PMS integration option and specify:

- The selected PMS integration type should be **Fidelio**.
- Enter the **local IP address** of the PMS System.
- The **port** must match the one configured in the PMS system on your LAN.

The 3CX Hotel Service will restart and load the necessary parameters to communicate with the respective PMS.

**Note**: When using the Fidelio protocol a billing interface is implemented in the protocol to advise the PMS of generated calls made by the room (including time, destination and advised cost based on the 3CX configured charges for the destination). The PMS might use all information or for more specific needs it will recalculate the cost.

## Global Company Phonebook Update for Hotel IP Phones & DECT

This function allows hotel administrators to control how often IP phones and DECT devices automatically check for updates to the phonebook. This is particularly useful in hotel environments where room changes when assigning/clearing rooms may occur frequently.

1. Go to Admin Console > Phones > Options.
2. Locate the **Global Company Phonebook Update** section.
3. Set the desired interval for each phone brand.
