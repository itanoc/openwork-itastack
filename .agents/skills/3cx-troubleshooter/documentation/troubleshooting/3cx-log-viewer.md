# Analyse SIP Communications with 3CX Log Viewer

> Source: https://www.3cx.com/docs/3cx-log-viewer/

## Introduction

The 3CX Bin Log Viewer is used to read and filter the logs generated by the 3CX Phone System, which allows users to build advanced filters and easily sieve through logs.

## Installation

The 3CX Bin Log Viewer can be downloaded and installed directly from the 3CX Admin Console.

Download: [3CX Bin Log Viewer V15](https://downloads.3cx.com/downloads/misc/3cxBinLogViewer15.zip)

## 3CX Bin Log Viewer Overview

The first time you load the 3CX Log Viewer, click on File > Open and navigate to the location where 3CX logs are stored. The Bin Log Viewer shall not be used directly on the 3CX host to avoid performance implications with the live system. Generate a support bundle from the 3CX Management Console and download it to your PC where the Bin Log Viewer is running. Extract the ZIP file and within the /Logs folder you will find a file named **"3CXPhoneSystem.bldef"**.

The 3CX Bin Log Viewer consists of four main sections:

1. **Filtering Options** - Build filters by date, time, extension, call ID, and tags
2. **Log Window** - Displays the filtered log entries
3. **Tags Window** - Lists available tags for filtering
4. **Detail Window** - Shows detailed information about selected log entries

## Filtering Options

You can filter by:
- Date and time range
- Extension number
- Call ID
- Tags (e.g. SIP, IVR, Queue)
- Custom text search

## Useful Tags

Common tags for troubleshooting:
- **SIP** - SIP signaling messages
- **IVR** - Digital receptionist activity
- **Queue** - Call queue operations
- **Trunk** - SIP trunk activity
- **Auth** - Authentication events
- **DNS** - DNS resolution
- **Media** - RTP/media stream events

## Other Features

- Export filtered results
- Bookmark important log entries
- Color-coded log levels

## Information on the 3CX Server Logs

The 3CX Phone System generates binary log files that can only be read with the Bin Log Viewer. These logs contain detailed information about all system activities including call processing, SIP messaging, and system events.
