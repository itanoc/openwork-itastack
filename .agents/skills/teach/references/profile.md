# Learner profile

Build `.teach/LEARNER.md` so later sessions can teach the same mind consistently.

## Interview

Ask 2–3 questions per turn, then wait. Cover every area without asking all at once:

1. Solid ground: subjects and notation the learner already holds.
2. Goal: the observable result they want next.
3. Pace: default to one reasoning step followed by a quiz.
4. Struggle: which thinking the learner wants to do themselves.
5. Voice: density, tone, language, and disliked AI habits.
6. Artifacts: editor, Obsidian, or another Markdown workflow.

Use a safe structured picker when it fits; otherwise ask plain conversational questions. Profile questions are not graded.

## Write

Create `.teach/LEARNER.md` from [the learner template](../assets/LEARNER.md). Use the learner's words where practical and leave unknown fields blank.

If the file already exists, show the proposed changes and wait for explicit approval before editing it.

The profile is complete when every interview area is either populated or explicitly declined. Show the saved path and offer to probe the current goal.
